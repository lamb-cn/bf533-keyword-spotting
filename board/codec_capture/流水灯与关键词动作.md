# BF533 关键词识别与流水灯说明

## 命令动作

初始时 LED4 到 LED9 全灭，当前选中位置为 LED4。

| 识别词 | 动作 |
| --- | --- |
| four、five、six、seven、eight、nine | 翻转对应的 LED4 到 LED9，并将其设为当前选中位置 |
| left | 将当前选中位置移到左侧相邻灯，翻转该灯 |
| right | 将当前选中位置移到右侧相邻灯，翻转该灯 |
| go | 从当前选中灯开始，启动单灯向右循环的流水灯 |
| stop | 停止流水灯，恢复启动前的手动灯状态 |
| off | 停止流水灯，并熄灭全部灯 |
| silence、unknown | 不改变灯状态 |

左右移动在 LED4 和 LED9 两端循环相接。数字或方向命令在流水灯运行时，会先停止流水灯，再对手动灯状态执行相应翻转。

## 流水灯时序

采样每 20 ms 形成一个音频块。流水灯每经过 6 个音频块前进一格，即每 120 ms 移动到右侧下一盏灯。运行位置以选中灯为起点，经过 LED9 后回到 LED4。

流水状态更新放在主循环的音频块处理路径中，不在中断服务程序中等待定时，也不使用阻塞延时。

## 运行与验证

连接 BF533 EZ-KIT Lite 和电脑音频输出后，在仓库根目录运行：

```powershell
.\board\codec_capture\run_listen.ps1
```

CCES 启动后播放关键词，板载 LED 即显示对应行为。停止持续监听可在终端按 Ctrl+C。

构建单词表和板上模型镜像：

```powershell
.\board\codec_capture\prepare_model.py
```

上板程序使用 13 类 INT8 权重。流水灯状态机的仿真检查与两个上板 DXE 的编译由 CCES 完成。物理板上的实时识别效果仍需接入音频后确认。
