# BF533 CNN ASM Implementation Plan

Goal: verified, timed three convolution operators on BF533 simulator.
Spec: ../specs/2026-10-29-cnn-asm-design.md
Architecture: paired-output packed matvec plus direct paired-channel depthwise, C layer wrappers and independent C oracle.
Tech: CCES 2.10, Blackfin assembly, PowerShell automation.

1. Write simulator tests and runner first; confirm an empty assembly stub produces mismatches. Tests catch wrong signed scaling, lane selection, padding, tensor layout and loop endpoints.
2. Implement dual MAC matrix kernel and direct nine-tap depthwise kernel. Compare all full-size results, deterministic random, zero and signed-extreme cases. Preserve ABI and bounded reads.
3. Measure C versus ASM and preprocessing/postprocessing independently. Export result records from discovered ELF symbols, never fixed addresses. Document cycles and L1 storage.
4. Review final sources and rerun full suite; retain reproducible runner and report.

Ruling: directory is not a Git repository; keep artifacts under work/cnn_asm without initializing Git or creating a worktree. Model synthetic operator validation only; MFCC and trained inference remain outside scope.
