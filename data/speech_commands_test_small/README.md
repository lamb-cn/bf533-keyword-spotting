# Speech Commands 13 类仿真抽样

音频来自 Google Speech Commands v0.02。用固定随机种子 533 从官方 `testing_list.txt` 为 11 个关键词及非目标词各抽取三条。数字静音由本项目生成。原路径和期望标签见 [manifest.json](manifest.json)。原始录音遵循随附的 [CC BY 4.0](LICENSE)。

数据出处：[Google Speech Commands v0.02](https://storage.googleapis.com/download.tensorflow.org/data/speech_commands_v0.02.tar.gz)，Pete Warden，Speech Commands: A Dataset for Limited-Vocabulary Speech Recognition。
